Two footings. Dotted grey = witness–effect pairings and containments. Long-dashed teal exclusion equivalences (⇔¬): the source holds iff the target FAILS (classical ⇔ no entanglement / no incompatibility / no contextuality) — the sign sits on the edge, not in the prose. Long-dash single-arrow = a model hosting a state cluster. Dashed red = counterexamples. Copper = derived in this project (N1, P1–P3, GN5). Dotted violet = open edges.
